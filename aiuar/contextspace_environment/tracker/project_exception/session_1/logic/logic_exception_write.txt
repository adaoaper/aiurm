L1. Exception write policy
- Receive *data_exception_event from the calling business project.
- *data_exception_event must contain:
    origin_contextspace         : contextspace of the calling project
    origin_entity               : entity of the calling project
    origin_project              : project name of the calling project
    origin_aiuar_logic_source : full resolved AIUAR session address of the executing business project’s logic source
    origin_aiuar_data_source : full resolved AIUAR session address of the executing business project’s data source
    origin_aiuar_result_output : full resolved AIUAR session address of the executing business project’s designated result destination
    timestamp                   : YYYYMMDD_HHMMSS
    step                        : R block where the exception occurred
    title                       : step title
    exception_type              : UNRESOLVABLE_MARKER | EXECUTION_FAILURE | VALIDATION_ERROR | custom
    marker                      : the marker that failed (if applicable)
    expected_in_governance_section : Data | Logic | null
    governance_declared         : true | false
    artifact_found              : true | false
    action                      : ABORTED | SKIPPED | RETRIED
    executor_insight            : optional diagnostic message from the executor
- Exception records are quarantined for inspection — never auto-deleted.
- Emit the result artifact with full exception content.
- For the record marker, derive {result_output_session} from the session name in origin_aiuar_result_output (e.g. session_2).
