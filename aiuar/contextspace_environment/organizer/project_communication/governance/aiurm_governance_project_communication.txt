# Workflow
Environment — Communication Project (v0.1-experimental)
Generic Agent-to-Agent Coordination over Filesystem

# Purpose
Generic coordinator for the co-execution of any target AIUAR project by two agents.
Co-execution is launched on the target, never on this project:
execute ***{target_project}*governance as {agent_self} in co-execution with {agent_peer} coordinated by ***project_communication*governance
The target pipeline is executed under its own governance contract; this project only governs
turn-taking. It knows nothing about the target's steps: progress is carried only by the message
artifacts in this session's result. Before each target Result step the agent claims the peer's
message (proof that the peer finished its step) and is granted one turn; after the step it
publishes a message *result_communication_{timestamp}_{randomid} (from/to in body) identifying
the target and the step resolved. Flow per turn: claim -> one target Result step -> send.
The loop ends when the target pipeline has no unresolved step (END message).
